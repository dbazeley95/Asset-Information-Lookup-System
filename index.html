Release Notes

1.14

CORS for the XCET Assets Tool

The lookup API (/api/warranty/<vendor>) now allows cross-origin requests from https://assets.xcet.uk, so that tool can call it directly from browser JS — no need to open this page at all. Allow-listed origins are extendable via a CORS_ALLOWED_ORIGINS Worker variable; see the README.

1.13

Deep Linking From Other Tools

Another tool can now link straight into a lookup with a URL like ?vendor=dell&serial=7XJ4K52 — it selects the right tab and runs the lookup automatically. Works for any vendor with a live lookup (Apple and Dell today, Lenovo automatically once its ClientID lands). See the README for the full parameter reference.

1.12

Lenovo Marked Pending, With a Manual Fallback

Lenovo's lookup is built (see 1.11) but not live yet — still waiting on a ClientID from Lenovo. Its tab now reads "Pending", and the lookup form itself shows greyed out and genuinely disabled (not just visually) with a link to Lenovo's own manual warranty lookup above it, so there's still a usable path in the meantime. Switches back to a normal working lookup with no other changes once the credentials are in place.

1.11

Lenovo Now Looks Up Natively

Lenovo moves from "External" to a real, built-in lookup — via Lenovo's eSupport WebAPI, using a ClientID (issued by a Lenovo Account Representative or Partner Program, not an online signup form). Tabs are now Apple, Dell, HP, Lenovo, SMART Tech. HP and SMART Tech stay External for now — see the README for what it'd take to bring either in-house.

1.10

SMART Technologies, Badged External

Added SMART Tech as a fourth "External" tab, alongside HP and Lenovo — opens SMART Technologies' own product warranty lookup in a new tab.

1.9

HP and Lenovo, Badged External

Tabs are now Apple, Dell, HP, Lenovo. HP and Lenovo aren't wired into this tool's own lookup — their tab is badged "External" (not dimmed like "Coming soon", since this is a real, usable path) and opens straight through to the manufacturer's own official warranty lookup tool in a new tab instead of searching here.

1.8

Warranty (In Months) Badge

Each result card now shows a rounded "N mo" badge next to the status badge — the warranty length in months, from ship date to warranty end date. It's there to read straight into the Freshservice Asset Import tool's Warranty (In Months) field when importing devices, instead of having to work it out from the dates by hand.

1.7

Apple Lookups Now Retry Transient Errors

Apple requests (token, device list pages, coverage) now retry automatically with backoff on transient failures — 520/521/522/523/524/525/526/530 (Cloudflare edge error codes, since Apple's API is evidently served through Cloudflare too) and the usual 429/502/503/504. Since a full device-list fetch can mean dozens of sequential page requests for a large organisation, one blip used to fail the whole lookup; now it's retried up to 3 times with exponential backoff before giving up. Genuine failures (bad credentials, not found, etc.) are unaffected and still fail immediately.

1.6

Apple First, and a Heads-Up on First-Lookup Speed

Manufacturer tabs now read Apple, Dell, Lenovo (was Dell, Lenovo, Apple). The Apple tab also shows a note that the first lookup after a while can take longer than Dell's, since it pages through the organisation's full device list before it can match a serial — the result is cached afterwards, so follow-up lookups are quick.

1.5

Clearer Errors When Apple Credentials Are Misconfigured

"APPLE_ORGS is not valid JSON" used to cover several genuinely different problems with one identical message — unset, malformed JSON, valid JSON that isn't an array (e.g. got wrapped in an extra pair of quotes somewhere), an empty array, or an org entry missing a required field. Each now gets its own specific message, so a still-broken setup after a first fix attempt is actually diagnosable from the error text alone. No functional change to working Apple lookups.

1.4

Apple Lookup Fixes, Confirmed Against a Working Script

Three fixes to the Apple integration added in 1.3, based on a working PowerShell script already in use here: the API host now correctly points at api-school.apple.com (was defaulting to the Business Manager host); the token request's aud claim now uses the correct separate v2 URL instead of reusing the token endpoint's own URL; and device lookup now pages through each org's full device list rather than relying on a per-serial filter that doesn't actually work, caching the result for 30 minutes per org so repeat lookups stay fast. No visible UI changes.

Help Guide

1. Pick a manufacturer

Use the tabs near the top — Apple and Dell look up automatically here. Lenovo is marked "Pending": its lookup form is built but greyed out until API access comes through, with a link to Lenovo's own manual lookup shown above it in the meantime. HP and SMART Tech are marked "External": neither is wired into this tool at all, so their tab links straight through to the manufacturer's own official warranty lookup instead.

2. Enter service tags or serial numbers

Type or paste one or more into the box — one per line, or separated by commas or spaces. Up to 20 at a time. Click Look Up Information (or press Ctrl/Cmd + Enter from the box).

For Apple, if more than one Apple School/Business Manager organisation is configured, every one of them is searched automatically — you don't need to know in advance which school or org a device belongs to.

3. Read the results

Each entry gets its own card: model, ship date, a status badge (Active/Expired/Unknown), a warranty-length badge in months, the warranty end date, and a table of every coverage entry on file with its own start/end dates. The months badge is rounded from ship date to warranty end date — it's there to read straight into the Freshservice Asset Import tool's Warranty (In Months) field. An Apple result also shows which org it was found in. An entry with no data on file shows an explanation instead.

Settings

The gear icon (top right) opens Theme (System/Light/Dark), this Help guide, Release Notes, Leave Feedback, and — on browsers that support it (Chrome/Edge) — Install App, which adds a standalone, taskbar/home-screen-pinnable copy. Safari/iOS has no equivalent Install button, but Add to Home Screen from the Share sheet works there instead.

Your data

Nothing you search is stored. Each lookup is proxied through a Cloudflare Worker straight to the manufacturer's own API and back — no database, no logging, no analytics.
